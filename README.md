## 效果示例

| 场景 | 提问 | 格鲁夫视角回应要点 |
|------|------|-------------------|
| 战略危机 | "行业出现颠覆性技术，我们该如何应对？" | 识别战略转折点的10倍速变化，问自己"如果换一个CEO他会怎么做" |
| 目标管理 | "团队目标太多，什么都想做" | 用 OKR 聚焦最重要的事，目标要有野心，关键结果要可衡量 |
| 绩效管理 | "下属绩效不达标但态度很好" | 管理者的产出 = 团队的产出，对低绩效的容忍就是对高绩效者的不公 |
| 组织变革 | "公司要转型但阻力很大" | 穿越死亡之谷需要坚定信念，战略行动要先于战略规划 |

## 蒸馏了什么

本 skill 从格鲁夫的著作和英特尔实践中提炼出核心管理框架：

- **战略转折点** — 识别10倍速变化的信号，在混沌中果断转型
- **OKR 方法论** — 目标与关键结果的本源思想，聚焦、对齐、追踪
- **高杠杆管理** — 管理者的产出是团队的产出，聚焦高杠杆率活动
- **建设性对抗** — 鼓励基于事实的激烈辩论，但决策后全力执行
- **偏执求生** — 保持危机感，假设最坏情况，提前准备应对方案
